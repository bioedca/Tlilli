# Skills

The skill sources (`tlilli-run`, `tlilli-revise`, `tlilli-stub` and the rest of the pack described in the concept and in [PRD 11](../docs/prd/11-fr-v0.2-red-ink.md)) land in this directory in v0.2, when `tlilli skills build` turns them into per-client packages for Claude Code, Codex and the MCP prompts. Everything under `skills/` is licensed under the MIT License ([LICENSE](LICENSE)) so that people and agents can reuse the text freely; the rest of the repository is Apache-2.0. The policy is in [docs/dev/licensing.md](../docs/dev/licensing.md).
