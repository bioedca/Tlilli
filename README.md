**Status: pre-alpha, Phase 0 (Foundation).** There is nothing to install yet; the repository holds the [requirements](docs/prd/README.md) and the scaffolding. The first release, v0.1 "Black ink", is the editor without an agent.

Tlilli is a local desktop manuscript editor that turns any MCP-capable coding agent into a disciplined scientific co-editor: strict turns, every change anchored to a sentence, attributed to whoever wrote it, and reversible. The author writes in black ink (*tlilli*, the Nahuatl word for it). The agent, connected over the Model Context Protocol, writes only red ink (*tlapalli*): suggestions with alternatives, comments, verified citations and a short allow-list of mechanical fixes. Accepting a proposal turns red to black, and the manuscript (*amoxtli*) remembers which was which. The app owns what a chat window never has: the manuscript as structured, addressable text with stable sentence IDs, the citation ledger with sources, full text and claim links, the style sheet, and the run history.

## What it is not

- **Not a chat.** No prompt box; work is marked up in the text and sent as a batch.
- **Not a model host.** No API keys, no model picker; the agent subscription you already have does the thinking.
- **Not a reference manager.** A per-manuscript ledger with import from identifiers, PDFs and, later, Zotero.
- **Not a cloud service.** No accounts, no server, no telemetry; the workspace is a folder on your disk.

## Install

Installers for macOS, Windows and Linux appear on the [releases page](https://github.com/bioedca/Tlilli/releases) from v0.1. The install pages of the [documentation site](https://bioedca.github.io/Tlilli/) cover each operating system, the prompts an unsigned application triggers, and how to verify a download with its checksum and attestation. Until then, build from source once the Cargo workspace lands ([CONTRIBUTING.md](CONTRIBUTING.md)).

## Quick start

The first tutorial, "your first manuscript", arrives with v0.1: create a workspace, import a draft, mark up a sentence, take a snapshot, export. Connecting an agent (Claude Code, Codex CLI) is v0.2; the agent how-to pages live on the documentation site.

## Built with agents

Most of the code and documentation is written by AI coding agents (Claude Code, Codex) and reviewed by AI reviewers, under a process that one human maintainer defined and gates; every commit is signed off by that maintainer under the Developer Certificate of Origin. The explanation page `docs/explanation/built-with-agents.md` (`PR-DOC-014`) records how the agents shape the work.
