# Gate G3: v0.3.0 Ledger

The acceptance script of milestone `v0.3 Ledger` (`PR-GATE-003`). It is followed literally at the gate and changes only in gated pull requests. The steps are those of [40 Roadmap and gates](../prd/40-roadmap-and-gates.md) §3; the gate procedure, the verdict and what follows a pass or a fail are in §2 of that page.

## Before you start

- [ ] The release under test is published, and you install it from the GitHub Release on at least your primary operating system (`PR-GATE-001`).
- [ ] The manuscript is your own, or a co-author's with consent. The report records metrics and redacted notes only, never text, and you decide which agent vendor may see which manuscript (`PR-GATE-002`).
- [ ] A gate report is open, from the "Gate test report" issue form, with this page as the script followed.

## Steps

Record each step as pass or fail with a note. Where a step names FR IDs, mark each one verified, failed or deferred (with its D-nnn), and check every `INV-*` that applies to the phase (`PR-GATE-004`).

- [ ] **1.** Add 10 sources by DOI/PMID, 5 by PDF drop (DOI sniffed), 5 proposed by the agent during a run; dedupe prompt exercised (`FR-03-001..005`).
- [ ] **2.** Link 20 citations; run citation verification as a standing check with Claude Code; author judges statuses: ≥ 90% agreement (`FR-03-020..031`, metric).
- [ ] **3.** A `contradicted` and an `unsupported` case planted; agent follow-ups present per `FR-03-013`.
- [ ] **4.** Export CSL-JSON (opens in Zotero), BibTeX (compiles), Markdown with references in two styles and one non-English locale (`FR-03-050..052`).
- [ ] **5.** Recording proxy confirms only allow-listed hosts contacted (`NFR-SEC-004`); offline mode queues an add and resolves later.
- [ ] **6.** Malformed PDF fixture does not crash the app (`NFR-SEC-005`).
