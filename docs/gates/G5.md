# Gate G5: v0.5.0 Beyond the article

The acceptance script of milestone `v0.5 Beyond the article` (`PR-GATE-003`). It is followed literally at the gate and changes only in gated pull requests. The steps are those of [40 Roadmap and gates](../prd/40-roadmap-and-gates.md) §3; the gate procedure, the verdict and what follows a pass or a fail are in §2 of that page.

## Before you start

- [ ] The release under test is published, and you install it from the GitHub Release on at least your primary operating system (`PR-GATE-001`).
- [ ] The manuscript is your own, or a co-author's with consent. The report records metrics and redacted notes only, never text, and you decide which agent vendor may see which manuscript (`PR-GATE-002`).
- [ ] A gate report is open, from the "Gate test report" issue form, with this page as the script followed.

## Steps

Record each step as pass or fail with a note, as the gate report form asks ([36](../prd/36-issues-labels-and-projects.md) §1). Where a step names FR IDs, mark each one verified, failed or deferred (with its D-nnn), and check every `INV-*` that applies to the phase (`PR-GATE-004`).

- [ ] **1.** Import a protocol; draft a Methods paragraph from a `protocol:` stub; provenance link to the protocol passage (`FR-05-001..003`).
- [ ] **2.** Create a reviewer response from two reviewer reports; draft responses with Codex; cross-link; `response_check` finds a planted unfulfilled promise; export docx (`FR-05-010..013`).
- [ ] **3.** Draft a cover letter from abstract and significance stub (`FR-05-020`).
- [ ] **4.** Shared pool used by two manuscripts; Zotero import of a 50-item collection via Better BibTeX export and via the local API (`FR-05-030..041`).
- [ ] **5.** ChatGPT Developer-mode connector through the tunnel: `verify-citations` prompt runs; tunnel stops with the app; token required (`FR-05-050..052`, `NFR-SEC-006`).

## Metrics

The report records the success metrics for the phase from [01 Vision and scope](../prd/01-vision-and-scope.md) §6, each met or waived with a decision entry (`PR-GATE-005`), and the velocity figures of `PR-GATE-008`.
