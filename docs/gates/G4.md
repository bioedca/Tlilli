# Gate G4: v0.4.0 Sweep and style

The acceptance script of milestone `v0.4 Sweep and style` (`PR-GATE-003`). It is followed literally at the gate and changes only in gated pull requests. The steps are those of [40 Roadmap and gates](../prd/40-roadmap-and-gates.md) §3; the gate procedure, the verdict and what follows a pass or a fail are in §2 of that page.

## Before you start

- [ ] The release under test is published, and you install it from the GitHub Release on at least your primary operating system (`PR-GATE-001`).
- [ ] The manuscript is your own, or a co-author's with consent. The report records metrics and redacted notes only, never text, and you decide which agent vendor may see which manuscript (`PR-GATE-002`).
- [ ] A gate report is open, from the "Gate test report" issue form, with this page as the script followed.

## Steps

Record each step as pass or fail with a note, as the gate report form asks ([36](../prd/36-issues-labels-and-projects.md) §1). Where a step names FR IDs, mark each one verified, failed or deferred (with its D-nnn), and check every `INV-*` that applies to the phase (`PR-GATE-004`).

- [ ] **1.** Apply the target journal preset; set limits, abbreviations, terminology, auto-fix list, two locked spans (`FR-04-001..004`).
- [ ] **2.** Plant 10 inconsistencies; run the sweep with Codex; ≥ 8 found, ≤ 3 false positives (`FR-04-010..012`, metric).
- [ ] **3.** Accept mechanical renumbering and abbreviation fixes; revert one; cancel a run with mechanical edits → auto-reverted (`FR-04-020..022`).
- [ ] **4.** Figures: a missing panel reference and a wrong order planted; `figure_check` finds both; caption rewrite via suggestion; image resource read by a vision-capable client (`FR-04-030..033`).
- [ ] **5.** Export docx with comments → co-author opens in Word and LibreOffice, reads comments, returns a docx whose comments import (`FR-04-040`, `FR-04-043`).
- [ ] **6.** LaTeX export compiles with `latexmk`; PDF via Typst renders with references (`FR-04-041..042`).
- [ ] **7.** Provenance summary and disclosure paragraph produced and edited (`FR-04-044`).
- [ ] **8.** Mutation score report ≥ 70% on core (`PR-TST-012`).

## Metrics

The report records the success metrics for the phase from [01 Vision and scope](../prd/01-vision-and-scope.md) §6, each met or waived with a decision entry (`PR-GATE-005`), and the velocity figures of `PR-GATE-008`. First measured at this gate:

| Metric | Target |
| --- | --- |
| Consistency sweep true positives on a seeded manuscript (10 planted errors) | ≥ 8 found; ≤ 3 false positives |
| docx export opened without repair prompts in Word and LibreOffice; comments visible | 100% of gate manuscripts |
