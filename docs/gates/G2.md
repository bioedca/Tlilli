# Gate G2: v0.2.0 Red ink

The acceptance script of milestone `v0.2 Red ink` (`PR-GATE-003`). It is followed literally at the gate and changes only in gated pull requests. The steps are those of [40 Roadmap and gates](../prd/40-roadmap-and-gates.md) §3; the gate procedure, the verdict and what follows a pass or a fail are in §2 of that page.

## Before you start

- [ ] The release under test is published, and you install it from the GitHub Release on at least your primary operating system (`PR-GATE-001`).
- [ ] The manuscript is your own, or a co-author's with consent. The report records metrics and redacted notes only, never text, and you decide which agent vendor may see which manuscript (`PR-GATE-002`).
- [ ] A gate report is open, from the "Gate test report" issue form, with this page as the script followed.

## Steps

Record each step as pass or fail with a note, as the gate report form asks ([36](../prd/36-issues-labels-and-projects.md) §1). Where a step names FR IDs, mark each one verified, failed or deferred (with its D-nnn), and check every `INV-*` that applies to the phase (`PR-GATE-004`).

- [ ] **1.** Install `v0.2.0`; enable the MCP server; connect Claude Code via stdio and Codex CLI via HTTP with the token (`FR-02-010..012`).
- [ ] **2.** Run 7 scenario on the Introduction with Claude Code: 3 requests + untagged comment; agent turn ≤ 5 min; report; review: accept edited alternative, accept stub draft, reject move with redo, close (`FR-02-001..045`).
- [ ] **3.** Repeat with Codex; compare behaviour; both skill packages installed by copying (installer at v1.0).
- [ ] **4.** Attempt forbidden actions from a scripted client: write without claim, out-of-scope target, locked span, 4 alternatives, missing rationale, oversize payload: all refused (`INV-01`, `INV-03`, `FR-02-030..036`).
- [ ] **5.** Timeout drill: stop the agent mid-run; run times out at the configured 5 min; suggestions stay as red ink; editor unlocks (`NFR-REL-004`).
- [ ] **6.** Rollback a run; History shows diffs, report and tool log (`FR-02-044..045`).
- [ ] **7.** Show ink: provenance marks correct; percentages per section (`FR-02-050..051`).
- [ ] **8.** Updater: point the app at a staged `beta.json`; check, see notes, install the beta build, relaunch (`FR-02-070`); verify request carries no identifiers.
- [ ] **9.** Metrics: author time per cycle ≤ 10 min; accepted share ≥ 50%; zero author-text overwrites.

## Metrics

The report records the success metrics for the phase from [01 Vision and scope](../prd/01-vision-and-scope.md) §6, each met or waived with a decision entry (`PR-GATE-005`), and the velocity figures of `PR-GATE-008`. First measured at this gate:

| Metric | Target |
| --- | --- |
| Author time per cycle (mark-up + review, excluding agent time) for a 3-request run | ≤ 10 min |
| Agent turn wall-clock for a 3-request run on an Introduction | ≤ 5 min typical; ≤ 30 min hard timeout |
| Author-text overwrites by an agent | 0, ever |
| Suggestions accepted (any alternative, with or without edit) per run on a real manuscript | ≥ 50% |
