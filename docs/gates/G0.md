# Gate G0: Phase 0 Foundation

The acceptance script of milestone `0 Foundation` (`PR-GATE-003`). It is followed literally at the gate and changes only in gated pull requests. The steps are those of [40 Roadmap and gates](../prd/40-roadmap-and-gates.md) §3; the gate procedure, the verdict and what follows a pass or a fail are in §2 of that page.

## Before you start

- [ ] A gate report is open, from the "Gate test report" issue form, with this page as the script followed. Phase 0 has no release ([40](../prd/40-roadmap-and-gates.md) §1): this gate tests the repository and its automation, so there is no release build or manuscript.

## Steps

Record each step as pass or fail with a note, as the gate report form asks ([36](../prd/36-issues-labels-and-projects.md) §1). Phase 0 has no FR file ([40](../prd/40-roadmap-and-gates.md) §1), so no step below names an FR ID to mark under `PR-GATE-004`.

- [ ] **1.** Account and repository settings per [39](../prd/39-github-configuration.md) (2FA, successor, Actions allow-list, rulesets, labels, forms, templates present); the audit checklist passes.
- [ ] **2.** A hello-world workspace (`crates/*` skeletons, `src-tauri`, `ui`) builds; `ci.yml` green with every required check reporting; a Draft PR by an agent (local or cloud session, D-078) goes through Codex → CodeRabbit → Ready → auto-merge or the agent's merge (branch up to date) → `main` with zero human clicks (ungated path), and a second PR touching a gated path is blocked until `gate:approved` (without the label, only the admin bypass on a relayed authorization recorded in the PR body can merge it, `PR-GIT-058`).
- [ ] **3.** `release.yml` rehearsed in the companion repo with `dry_run=true`; `docs.yml` deploys the skeleton site.
- [ ] **4.** DCO, commitlint, size, docs-sync, zizmor, Scorecard all report.

## Metrics

The report records the success metrics for the phase from [01 Vision and scope](../prd/01-vision-and-scope.md) §6, each met or waived with a decision entry (`PR-GATE-005`), and the velocity figures of `PR-GATE-008`. First measured at this gate:

| Metric | Target |
| --- | --- |
| Process: median PR lead time (open → merged) for agent PRs | ≤ 24 h |
| Process: PRs merged with zero human intervention on ungated paths | ≥ 80% |
