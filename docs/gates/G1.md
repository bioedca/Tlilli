# Gate G1: v0.1.0 Black ink

The acceptance script of milestone `v0.1 Black ink` (`PR-GATE-003`). It is followed literally at the gate and changes only in gated pull requests. The steps are those of [40 Roadmap and gates](../prd/40-roadmap-and-gates.md) §3; the gate procedure, the verdict and what follows a pass or a fail are in §2 of that page.

## Before you start

- [ ] The release under test is published, and you install it from the GitHub Release on at least your primary operating system (`PR-GATE-001`).
- [ ] The manuscript is your own, or a co-author's with consent. The report records metrics and redacted notes only, never text, and you decide which agent vendor may see which manuscript (`PR-GATE-002`).
- [ ] A gate report is open, from the "Gate test report" issue form, with this page as the script followed.

## Steps

Record each step as pass or fail with a note. Where a step names FR IDs, mark each one verified, failed or deferred (with its D-nnn), and check every `INV-*` that applies to the phase (`PR-GATE-004`).

- [ ] **1.** Install `v0.1.0` from the draft→published release (unsigned bypass documented) — `FR-10-003` draft text used.
- [ ] **2.** Create a workspace; import the maintainer's current draft from docx and from Markdown; import report lists unsupported constructs (`FR-01-040..041`).
- [ ] **3.** Edit for a 45-minute session: paragraphs, headings, a figure drop, a table; undo/redo across a restart (`FR-01-020`).
- [ ] **4.** Mark up 10 requests across sentence/paragraph/section levels with Cmd/Ctrl-K; lock two spans; add two idea stubs (`FR-01-021`, `FR-01-013`).
- [ ] **5.** Send → run opens → cancel → requests preserved (`FR-01-022`).
- [ ] **6.** Snapshot, edit a full pass over one section, diff; measure span-ID survival on the real revision (≥ 99%) (`FR-01-012`, metric).
- [ ] **7.** Export Markdown with and without markers; canonical export; re-import; byte-identical canonical JSON (`FR-01-042..043`).
- [ ] **8.** Kill the app during typing; relaunch; integrity check passes; ≤ 1 s loss (`NFR-REL-001..002`).
- [ ] **9.** Keyboard-only pass and axe audit on all screens (`NFR-USE-001..002`); dark/light.
- [ ] **10.** Diagnostics bundle produced and inspected for redaction (`NFR-PRIV-003`).
- [ ] **11.** Trademark search result recorded (D-035); `tlilli-core` on crates.io.

## Metrics

The report records the success metrics for the phase from [01 Vision and scope](../prd/01-vision-and-scope.md) §6, each met or waived with a decision entry (`PR-GATE-005`), and the velocity figures of `PR-GATE-008`. First measured at this gate:

| Metric | Target |
| --- | --- |
