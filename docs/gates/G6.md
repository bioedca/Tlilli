# Gate G6: v1.0.0 Public

The acceptance script of milestone `v1.0 Public` (`PR-GATE-003`). It is followed literally at the gate and changes only in gated pull requests. The steps are those of [40 Roadmap and gates](../prd/40-roadmap-and-gates.md) §3; the gate procedure, the verdict and what follows a pass or a fail are in §2 of that page.

## Before you start

- [ ] The release under test is published, and you install it from the GitHub Release on all three operating systems (`PR-GATE-001`).
- [ ] The manuscript is your own, or a co-author's with consent. The report records metrics and redacted notes only, never text, and you decide which agent vendor may see which manuscript (`PR-GATE-002`).
- [ ] A gate report is open, from the "Gate test report" issue form, with this page as the script followed.

## Steps

Record each step as pass or fail with a note. Where a step names FR IDs, mark each one verified, failed or deferred (with its D-nnn), and check every `INV-*` that applies to the phase (`PR-GATE-004`).

- [ ] **1.** Clean VMs (macOS 13 or newer arm64, Windows 11, Ubuntu 22.04): install from GitHub Release and from Homebrew/winget/Flathub respectively; verify checksums and `gh attestation verify`; first run ≤ 5 min to a completed run with the sample manuscript following the tutorial only (`FR-10-001..004`).
- [ ] **2.** `tlilli skills install --claude-code`, `--codex`, `--chatgpt`; `--check` reports drift after editing a skill (`FR-10-010..011`).
- [ ] **3.** Docs site: every quadrant present; search works; `latest`/`dev`; link check clean; newcomer dry run of CONTRIBUTING and setup completed by someone other than the maintainer (`FR-10-020..022`, `PR-DOC-018`).
- [ ] **4.** Root files complete; `CITATION.cff` validates; Zenodo DOI minted on publish (`FR-10-030..032`).
- [ ] **5.** Public-release checklist in [15](../prd/15-fr-v1.0-public.md) §5 all green; threat register reviewed; GOVERNANCE successor and backup admin named.
- [ ] **6.** Release runbook executed literally by following the doc (bus-factor drill).
