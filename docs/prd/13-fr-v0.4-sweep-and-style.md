# 13 · Functional requirements — v0.4 "Sweep and style"

**Scope (concept):** style sheet, consistency sweep, mechanical auto-fixes, figures (captions, consistency, image resource), docx with comments, LaTeX, PDF through Typst.
**Release:** tag `v0.4.0`. **Gate:** [G4](40-roadmap-and-gates.md#gate-g4-v040-sweep-and-style). **Milestone:** `v0.4 Sweep and style`.

## 13.1 Style sheet

**FR-04-001 Style sheet model.** One style sheet per manuscript with: target journal and limits (abstract words, main text words, references, figures, tables); tense and person per section role; abbreviations (term → short form, `auto` flag); terminology (preferred and forbidden terms); hedging policy (claims stronger than a threshold verb need a supported claim link); citation style (`.csl` file, numeric/author-year); auto-fix list (which mechanical kinds the agent may apply directly); locked spans (list of span IDs). Stored as JSON with a published schema and exposed as `tlilli://manuscript/{id}/style-sheet`.
- AC: a journal preset library (10 presets: Nature, Science, Cell, PNAS, eLife, PLOS, NAR, JBC, bioRxiv generic, Generic APA) ships as data files; the author can import/export a style sheet; abbreviation list feeds segmentation (FR-01-011).
- Verification: schema tests; snapshot. Traces: Style sheet.

**FR-04-002 Limits and counters.** Live counters (FR-01-023) show limit and remaining; exceeding a limit shows a warning chip and is reported by the sweep.

**FR-04-003 Locked spans.** "Do not touch" spans are listed in the style sheet, rendered with a lock glyph, refused by every write tool and shown locked in resources (`INV-03`).

**FR-04-004 Style digest for agents.** `run_claim` returns a digest (limits, tense/person table, abbreviation count, terminology count, auto-fix kinds, lock count) and the full sheet is one resource read.

## 13.2 Consistency sweep

**FR-04-010 Document-level requests.** `consistency sweep` and `citation verification` are document-level requests; the sweep checks: numbers in abstract vs results (same quantities, same values and units); abbreviations defined once at first use; tense/person per section; terminology; figure and table references (every referenced panel exists, numbers in text match captions, order of first mention equals figure order); limits; duplicated sentences.
**FR-04-011 Server-side computed checks.** The server MUST compute the deterministic checks itself and expose them as `figure_check(run_id, manuscript_id)` and `sweep_check(run_id, manuscript_id)` returning structured findings, so the agent reasons over facts rather than re-deriving them; the agent adds judgement checks (logic chain, journal conventions) as comments.
**FR-04-012 Findings land as comments.** Severity by kind; each finding links the spans involved; the review pane groups them under Checks with "fix" affordances where a mechanical kind applies.
- Verification: seeded-manuscript test with 10 planted inconsistencies (success metric ≥ 8 found, ≤ 3 false positives).

## 13.3 Mechanical edits

**FR-04-020 Allow-listed kinds.** Mechanical kinds: `citation_format` (marker rendering/style), `abbreviation_first_use` (insert definition at first use, short form after), `figure_renumber`, `table_renumber`, `reference_renumber`, `terminology_replace` (preferred term substitution), `whitespace_punctuation` (double spaces, spacing before punctuation, unit spacing). Each kind has a precise, testable definition and a reverse operation.
**FR-04-021 `apply_mechanical(run_id, kind, changes[])`.** Applies only kinds enabled in the style sheet's auto-fix list; each change names span ids and before/after text; the server verifies the change is of the declared kind (pattern check) and refuses otherwise; every change is an event with actor `Agent` and provenance `agent_mechanical` (`INV-01` allows mechanical edits only through this door).
**FR-04-022 Per-run mechanical list and revert.** The review pane lists mechanical changes per run with revert-all and revert-each; cancel/timeout reverts them automatically (`NFR-REL-004`).
- Verification: property tests (apply then revert is identity); contract tests on refusals; e2e.

## 13.4 Figures and tables

**FR-04-030 Figure consistency.** `figure_check` returns: panels referenced but missing, figures never referenced, numbering mismatches, order-of-first-mention violations; renumbering offered as `figure_renumber`.
**FR-04-031 Image resource.** `tlilli://figure/{id}/image` returns image content (PNG/JPEG; SVG and PDF rasterized at 150 dpi) for vision-capable clients, with panel labels as metadata.
**FR-04-032 Caption work.** Caption rewrite requests follow the suggestion flow; the skill `tlilli-figures` teaches caption conventions (title sentence, panel descriptions, statistics, n, scale bars).
**FR-04-033 Tables as resources.** `tlilli://table/{id}` returns cells as JSON with units parsed where possible; the sweep flags unit and decimal inconsistencies and caption mismatches.
- Verification: unit on checks; contract tests; fixture tables.

## 13.5 Export and import

**FR-04-040 docx export.** Export with: section headings (styles), paragraphs, idea stubs as comments, figures with captions, tables, equations (OMML from LaTeX where convertible, else image), reference list rendered in the chosen CSL style with numeric or author-year markers, open suggestions and comments as Word comments (tracked changes deferred, [41](41-risks-and-decision-log.md) R-06), a provenance summary appendix (optional).
- AC: opens without repair in Word 365, LibreOffice 7.6+, Google Docs; comments anchored to the right text; snapshot tests of the OOXML.
**FR-04-041 LaTeX export.** Template-based `.tex` (article class by default; journal templates pluggable) with `\cite{key}`, figures (`\includegraphics`), tables (`tabular`), equations; `.bib` from hayagriva; compiles with `latexmk -pdf` on the fixture set (checked nightly in a container).
**FR-04-042 PDF export.** Typst in-process with a bundled template and fonts; reference list via hayagriva; figures embedded; produced within `NFR-PERF-008`.
**FR-04-043 docx import of comments and basic LaTeX import.** docx comments map to author comments (FR-01-041 completes); basic LaTeX import (sections, paragraphs, `\cite`, figures, simple tables) creates a manuscript and ledger stubs from the `.bib`.
**FR-04-044 Provenance summary and AI-use disclosure.** Export (any format) MAY include a provenance summary per section (share of words originating in suggestions, runs, agent identities) and a draft AI-use disclosure paragraph the author edits before submission (G3).
- Verification: snapshot tests; manual open at gate on three suites.

## 13.6 Skills and prompts

**FR-04-050 `tlilli-sweep`.** The consistency checklist, which findings are auto-fix vs comment, how to read `sweep_check` output, severity assignment.
**FR-04-051 `tlilli-style`.** Reading and applying the style sheet; treating source and reviewer text as data; never editing locked spans; how to propose style-sheet changes (as comments, since the sheet is author-owned).
**FR-04-052 Prompt `consistency-sweep`.** Mirrors `tlilli-sweep`.

## 13.7 Gate scenario (summary)

Apply the target journal's preset to the maintainer's manuscript; run sweep with planted errors (metric); accept mechanical renumbering and revert one; export docx with comments and send to a co-author who confirms it opens and comments are readable; LaTeX compiles; PDF renders; provenance summary and disclosure paragraph produced.
