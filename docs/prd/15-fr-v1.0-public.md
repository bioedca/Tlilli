# 15 · Functional requirements — v1.0 "Public"

**Scope (concept):** installers for macOS, Windows and Linux, documentation site, `tlilli skills install`, a sample manuscript, license and contribution guide.
**Release:** tag `v1.0.0`. **Gate:** [G6](40-roadmap-and-gates.md#gate-g6-v100-public). **Milestone:** `v1.0 Public`.

## 15.1 Distribution

**FR-10-001 Installers.** GitHub Release assets per [37](37-releases-and-packaging.md): macOS `.dmg` (arm64 and x86_64) plus `.app.tar.gz` updater artifact; Windows `.msi` and NSIS `-setup.exe`; Linux `.AppImage`, `.deb`, `.rpm`; `SHA256SUMS`; `sbom.spdx.json`; `latest.json`; Sigstore attestations for every asset.
**FR-10-002 Channels.** Homebrew cask in `tlilli/homebrew-tap`; winget manifest `Tlilli.Tlilli`; Flathub `org.tlilli.Tlilli`; crates.io `tlilli-core`, `tlilli-mcp`, `tlilli-cli` with `cargo binstall` metadata.
**FR-10-003 Unsigned-binary guidance.** The download page and first-launch dialog explain the Gatekeeper and SmartScreen prompts, show how to verify checksums and attestations, and link the zero-cost trust posture explanation; the app itself never asks users to disable security settings.
**FR-10-004 Clean-machine install.** On a fresh VM per OS, install → open sample manuscript → connect Claude Code → complete one run in ≤ 5 min following the tutorial only.
- Verification: release workflow assertions; gate on three VMs.

## 15.2 Skills installer

**FR-10-010 `tlilli skills install --claude-code | --codex | --chatgpt [--global|--project <dir>]`.** Writes the built skill package for the chosen client (Claude Code: `SKILL.md` folders under `.claude/skills/` or `~/.claude/skills/`; Codex: `AGENTS.md` section with markers plus skills folder; ChatGPT: prints the prompt catalogue and connector URL), is idempotent, shows a diff before overwriting, and `--check` reports drift between installed and bundled skills.
**FR-10-011 Skill version coupling.** Installed skills record the app version; the app warns when installed skills are older than the running app (`NFR-COMPAT-004`).

## 15.3 Documentation and onboarding

**FR-10-020 Docs site complete.** Every Diátaxis quadrant populated per [35](35-documentation.md): tutorials (first manuscript; first run with Claude Code; first run with Codex; verify citations; export to docx), how-tos, generated reference, explanations; search; dark mode; `latest` and `dev` builds; link check clean.
**FR-10-021 Sample manuscript.** A CC-BY sample workspace (synthetic riboswitch paper from the concept's Run 7 example, with 20 OA sources and a style sheet) bundled with the app and downloadable; the tutorials use it.
**FR-10-022 In-app help.** Help menu links to docs, keyboard shortcuts overlay, "report a bug" (opens the issue form URL with version prefilled), "copy diagnostics".

## 15.4 Project files

**FR-10-030 Root files.** `README.md` (badges, what/why, quick start, agents, license, cite), `LICENSE` (Apache-2.0), `skills/LICENSE` (MIT), `NOTICE`, `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md` (Contributor Covenant 2.1), `SECURITY.md`, `SUPPORT.md`, `GOVERNANCE.md`, `CITATION.cff`, `CHANGELOG.md`, `.github/FUNDING.yml`. Present from Phase 0 ([42](42-bootstrap-backlog.md)); complete and reviewed at v1.0.
**FR-10-031 Name clearance.** Trademark search completed before v0.1.0 (D-035); result recorded in the decision log; v1.0 announces the name as cleared or renamed.
**FR-10-032 Zenodo DOI.** The v1.0.0 release is archived on Zenodo; `CITATION.cff` carries the concept DOI; README shows "Cite this repository".

## 15.5 Public-release checklist (exit criteria beyond FRs)

- All `INV-*` verified in the gate; no open `priority/P0` or `priority/P1` issues.
- Threat register reviewed (PR-SEC-005); `SECURITY.md` live; private vulnerability reporting enabled.
- Discussions enabled since v0.2 with the four categories; announcement drafted.
- `good first issue` backlog of ≥ 10 items for contributors; CONTRIBUTING tested by a newcomer dry run (INTERSECT: user-test docs).
- Support policy published ([38](38-maintenance-and-support.md)); `release/1.0` branch policy understood (created only when a backport is needed).
- OpenSSF Scorecard ≥ 7.0; Codecov patch gates green for 30 days; mutation score on `tlilli-core` ≥ 70%.
