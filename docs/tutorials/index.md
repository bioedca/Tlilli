# Tutorials

Tutorials are for newcomers. Each one takes you through a complete task on the sample manuscript, step by step, and ends with a result you can see. Tutorials teach by doing: they do not explain the design (see [Explanation](../explanation/index.md)) and they do not cover every option (see [How-to guides](../how-to/index.md)).

Each tutorial is the written form of a gate test (`PR-DOC-004`): at the gate of its milestone a newcomer, or the maintainer following it literally, runs it and files what goes wrong. `FR-10-020` requires the set below to be complete at v1.0; PRD 35 §2 names the pages.

| Tutorial | Milestone | What you do |
| --- | --- | --- |
| First manuscript | v0.1 Black ink | Create a workspace, import a draft, mark it up, take a snapshot, export |
| First run with Claude Code | v0.2 Red ink | Connect Claude Code and run the Run 7 scenario on the sample manuscript |
| First run with Codex | v0.2 Red ink | The same scenario with Codex |
| Verify citations | v0.3 Ledger | Attach sources, link claims to them and verify the links |
| Style and sweep | v0.4 Sweep and style | Set up a style sheet and run a consistency sweep |
| Reviewer response | v0.5 Beyond the article | Draft a response to reviewers from the manuscript and their comments |

Nothing is published here yet. The first tutorial lands with v0.1 and is an exit criterion of gate G1 ([40 Roadmap and gates](../prd/40-roadmap-and-gates.md)).
