# How-to guides

How-to guides are for people who already use Tlilli and have a task in front of them. Each guide is a numbered procedure written to you, the reader; it does not teach the basics (see [Tutorials](../tutorials/index.md)) and does not explain the design (see [Explanation](../explanation/index.md)).

PRD 35 §2 names the guides and `FR-10-020` requires the quadrant to be complete at v1.0. The guides arrive with the features they describe:

| Guide | Lands with |
| --- | --- |
| Install on macOS, Windows and Linux, including the unsigned-binary steps and how to verify checksums and attestations | v1.0 installers ([15 FR v1.0](../prd/15-fr-v1.0-public.md)) |
| Connect Claude Code; connect Codex; connect ChatGPT through the tunnel | v0.2 agents ([11 FR v0.2](../prd/11-fr-v0.2-red-ink.md)), v0.5 tunnel ([14 FR v0.5](../prd/14-fr-v0.5-beyond-the-article.md)) |
| Import a docx; export LaTeX; export PDF | v0.1 import ([10 FR v0.1](../prd/10-fr-v0.1-black-ink.md)), v0.4 export ([13 FR v0.4](../prd/13-fr-v0.4-sweep-and-style.md)) |
| Style sheet; locked spans | v0.4 |
| Zotero; shared pool | v0.5 |
| Diagnostics: every user-facing error message links to an anchor on this page (`PR-DOC-012`) | v0.1 onwards |
| Updater; uninstall | v1.0 |

Nothing is published here yet.
